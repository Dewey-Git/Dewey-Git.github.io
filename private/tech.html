这个站，和我会的

这一页不需要密钥。写在这里是为了省掉「你都会些什么」那一轮试探—— 先看东西，再决定要不要问。

这个站本身5 件

  • 前端 原生 HTML / CSS / JavaScript。没有框架、没有构建流程、没有第三方依赖，仓库拉下来就能跑。
  • 加密 浏览器原生 Web Crypto：PBKDF2-SHA256 派生（20 万次）→ AES-256-GCM 加密，明文只在你的内存里出现。
  • 分享 HMAC-SHA256 密钥流封装数据密钥，做成带有效期、可一次性的链接；密钥本身不进链接明文。
  • 托管 GitHub Pages 纯静态，部署在子路径下。没有服务端、没有数据库，所以也没有「服务器被拖库」这一说。
  • 构建 Node.js 脚本负责离线加密内容、签发令牌、校验密文与密钥是否配套——加解密参数两边必须一字不差。

能力范围按能独立交付写

  • 主力语言 Java 8 年 · Python 4 年 · Go 2 年
  • 中间件 Kafka、Redis、RabbitMQ、Nginx —— 用得最多的是 Kafka 的重放与顺序性
  • 数据栈 Oracle、PostgreSQL、Spark、Flink、Hive；做过核心库迁移与异构数据同步
  • 工程化 Docker、K8s、GitLab CI、灰度发布、链路追踪——从提交到上线的整条链路自己搭过
  • 架构 微服务拆分、分库分表、幂等与最终一致性设计；调度平台核心链路重构，峰值吞吐约 10 倍

不太行的先说清楚

  • 前端框架 能写，但不算强项。这个站是原生手写的，正好绕开了这一点。
  • 算法模型 到会调 API、会读论文的程度；训练、微调、推荐排序没做过上线项目。
  • 原生客户端 Android / iOS 没做过上线的东西，只到能改能调试。
  • 值守运维 部署、排障、看监控都可以；7×24 的值班表不接。
